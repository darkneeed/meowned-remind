# meowned ремайнд 📬

**meowned ремайнд** — Android-приложение для автоматической пересылки входящих SMS-сообщений в Telegram (в личные сообщения, группу, супергруппу или канал).

---

## 🚀 Основные возможности

- 🌐 **Два режима работы**:
  - **С сервером**: пересылка SMS на ваш собственный сервер (Webhook / REST API) через HTTP POST с телом JSON и авторизацией по токену.
  - **Без сервера**: отправка сообщений напрямую через Telegram Bot API без сторонних серверов.
- 💬 **Поддержка топиков/тем**: возможность пересылки в определенную тему (Thread ID) форума Telegram.
- ⚡ **Мгновенный перехват**: `BroadcastReceiver` с высоким приоритетом перехватывает SMS в реальном времени.
- 🛡️ **24/7 Работа в фоне**: `Foreground Service` с постоянным уведомлением и `BootReceiver` для автозапуска после перезагрузки телефона.
- 🎯 **Гибкая фильтрация**:
  - Фильтр по номеру отправителя (Все / Белый список / Черный список с поддержкой регулярных выражений).
  - Фильтр по тексту (только коды авторизации / игнорирование спама).
  - Поддержка Dual-SIM (Все SIM / Только SIM 1 / Только SIM 2).
- 📝 **Кастомизация шаблона**: поддержка HTML-форматирования и плейсхолдеров (`{sender}`, `{body}`, `{time}`, `{date}`, `{datetime}`, `{sim}`).
- 📜 **История и журнал**: локальная база данных Room с фиксацией статусов доставки и кнопкой «Повторить отправку» при ошибках.

---

## 🛠️ Стек технологий

- **Язык**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **Архитектура**: MVVM + Coroutines + StateFlow
- **Хранилище**: Room Database + DataStore Preferences
- **Сеть**: OkHttp
- **Мин. версия Android**: Android 8.0 (API 26) и выше (полная поддержка Android 14 / API 34).

## 📲 Быстрый старт и настройка

### 1. Создание Telegram-бота
1. В Telegram перейдите к боту **[@BotFather](https://t.me/BotFather)**.
2. Отправьте `/newbot` и задайте имя бота.
3. Скопируйте полученный **HTTP API Token** (вида `123456789:AAF_abcdef...`).
4. **Важно:** перейдите к своему новому боту и нажмите кнопку **/start** (чтобы бот мог отправлять вам сообщения).

### 2. Получение вашего Chat ID
1. Напишите боту **[@userinfobot](https://t.me/userinfobot)** в Telegram.
2. Он пришлет ваш числовой `Id` (например, `123456789`).
3. *(Для групп)*: добавьте бота в группу, выдайте права на отправку сообщений и укажите ID группы (начинается с `-100...`).

### 3. Начальная настройка в приложении
1. Установите и запустите приложение **meowned ремайнд**.
2. Предоставьте запрошенные разрешения: **SMS** и **Уведомления**.
3. При первом запуске появится окно начальной настройки с выбором режима:
   - **С сервером**: для отправки SMS на ваш Webhook / REST API сервер в формате JSON.
   - **Без сервера**: для прямой отправки в Telegram через Bot API.
4. Настройте выбранный режим:
   - **Для режима «С сервером»**: укажите URL сервера (например, `https://my-server.com/api/sms`), опциональный API-ключ/токен (будет отправлен в заголовках `Authorization: Bearer` и `X-API-Key`) и имя устройства.
   - **Для режима «Без сервера»**: укажите `Bot Token` и `Chat ID` (а также `Topic ID` при отправке в форумную группу).
5. Нажмите кнопку проверки подключения, чтобы убедиться в доступности endpoint / бота.
6. На вкладке **Главная** включите главный переключатель **"Служба активна"**.

#### Формат запроса в режиме «С сервером» (HTTP POST JSON):
```json
{
  "event": "sms_received",
  "sender": "+79991234567",
  "body": "Код подтверждения: 1234",
  "timestamp": 1700000000000,
  "sim_slot": 1,
  "device_name": "Pixel 7",
  "text": "📬 Входящее SMS..."
}
```

#### Поддерживаемые форматы QR-кодов:
- **Webhook URL**: `https://my-server.com/api/sms?api_key=secret`
- **Строка с разделителем**: `server|https://my-server.com/api/sms|secret_key|PhoneName`
- **JSON**: `{"server_url":"https://my-server.com/api/sms","api_key":"secret"}`
- **Telegram бот**: `bot_token|chat_id|topic_id` или deep link `meowned-remind://config?token=...&chat_id=...`

## 🔋 Важные системные настройки Android (для надежной работы 24/7)

На новых версиях Android (MIUI, HyperOS, EMUI, OneUI, ColorOS, OxygenOS):
1. **Отключите оптимизацию батареи**: Нажмите кнопку в приложении «Отключить ограничения батареи» (или *Настройки -> Приложения -> meowned ремайнд -> Батарея -> Без ограничений*).
2. **Автозапуск**: Разрешите автозапуск приложения при включении телефона.
3. **Закрепление в памяти**: В меню недавних приложений нажмите «Замок» на приложении.
